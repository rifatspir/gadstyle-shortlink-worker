How to test:
1. Upload this package to a new GitHub repo named gadstyle-shortlink-worker.
2. In Cloudflare Workers, choose Import a repository and select that repo.
3. Confirm the Worker name is gadstyle-shortlink-worker.
4. Let Cloudflare deploy.
5. Open /health on the Worker URL.
6. Open /api/test on the Worker URL.

Expected:
- /health returns ok:true and d1_connected:true.
- /api/test returns ok:true, includes shortlinks table, and shortlinks_count >= 4.
